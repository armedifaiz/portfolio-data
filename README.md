# portfolio-data

Assets and data files for [armedifaiz.github.io](https://armedifaiz.github.io).

## Structure

```
photos/          — Profile photos (JPG)
  data.json      — Photo metadata
certificates/    — Certificate images (JPG)
  data.json      — Certificate metadata
index.json       — Quick summary
```

## Usage

All files are accessible via raw GitHub:
```
https://raw.githubusercontent.com/armedifaiz/portfolio-data/main/photos/data.json
https://raw.githubusercontent.com/armedifaiz/portfolio-data/main/photos/{filename}.jpg
```
